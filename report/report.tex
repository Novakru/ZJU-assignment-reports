\question{1.2: Convolutional layers}
For either spatial dimension, the output length is
\[
 n_{\rm out}=\left\lfloor
 \frac{n_{\rm in}+2p-d(k-1)-1}{s}+1\right\rfloor.
\]
\begin{enumerate}[label=(\alph*)]
\item \texttt{nn.Conv2d(36,48,3,stride=2)} uses padding 0 and
dilation 1. The sizes are $\lfloor(224-3)/2+1\rfloor=111$ and
$\lfloor(160-3)/2+1\rfloor=79$.
\item \texttt{nn.Conv2d(36,72,4,stride=(2,1),padding=(1,2))}
gives $\lfloor(224+2-4)/2+1\rfloor=112$ and
$\lfloor(160+4-4)/1+1\rfloor=161$.
\item Kernel $(5,3)$ and dilation $(1,2)$ give effective kernel sizes
$(5,5)$. The sizes are $\lfloor(224+4-5)/2+1\rfloor=112$ and
$\lfloor(160+2-5)/3+1\rfloor=53$.
Both channel counts, 36 and 72, are divisible by 6, so six groups are valid.
\end{enumerate}

\question{3: ROI Align}
ROI Pooling quantizes ROI boundaries and bin boundaries onto the feature grid,
which can shift features relative to the original image. ROI Align retains
fractional coordinates and samples features by bilinear interpolation at
precisely located points within each bin, then aggregates those samples.
It removes this coordinate quantization [2, Sec.~3].

This alignment matters because instance segmentation assigns a label
to each pixel. Small shifts can displace mask boundaries or lose thin
structures even when a bounding box is acceptable.
The code illustrates one fractional sample on a $2\times2$ feature map.

\question{4: SMPL}
SMPL (Skinned Multi-Person Linear Model) is a learned parametric 3D human
body model. It produces a mesh from a template using shape-dependent
and pose-dependent blend shapes and linear blend skinning [3].
\begin{itemize}
\item $\boldsymbol\theta$ describes pose through joint rotations.
Standard SMPL uses 24 axis-angle rotations (72 scalars), including
the global root rotation.
\item $\boldsymbol\beta$ contains coefficients in a learned body-shape
space, controlling body proportions and build. A common setting
uses 10 shape coefficients.
\end{itemize}
Global translation is specified separately. Changing $\theta$ articulates
the body; changing $\beta$ changes its underlying shape.
The code gives the corresponding parameter array shapes.

\question{5: CLIP}
CLIP trains an image encoder and a text encoder on paired images and captions.
Normalized embeddings share a feature space. For $N$ pairs, let
$s_{ij}=\mathbf v_i^\top\mathbf t_j/\tau$, with learned temperature $\tau$.
The symmetric contrastive objective is [4, Sec.~2.3]
\[
 \mathcal L=-\frac{1}{2N}\sum_{i=1}^{N}
 \left[
 \log\frac{\exp(s_{ii})}{\sum_j\exp(s_{ij})}
 +\log\frac{\exp(s_{ii})}{\sum_j\exp(s_{ji})}
 \right].
\]
This favors matching image-caption pairs over mismatched pairs in the batch.

For zero-shot classification, turn each candidate class into a text
prompt (for example, \emph{a photo of a dog}), encode the prompts and
image, and choose the class with greatest cosine similarity.
The pretrained encoders provide a classifier without fitting it to labeled
examples from the target task [4, Sec.~3.1].
The code computes the loss and class scores for two example embedding pairs.
