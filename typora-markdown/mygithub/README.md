# My GitHub Typora 主题

`mygithub.css` 基于 Typora 内置 GitHub 主题调整，适合中文笔记和 Markdown 文档。它使用 Open Sans 与霞鹜文楷作为英文字体和中文字体回退，调整代码字体，并将侧边栏改为类似 Drake 的彩色风格；自定义片段在 CSS 中以 `@nenhang` 标注。

## 安装与使用

将 `mygithub.css` 复制到 Typora 的主题目录，在 Typora 的主题菜单中启用。字体显示依赖本机已安装的字体；主题使用的字体和获取方式见 [fonts/README.md](fonts/README.md)。

## 兼容性说明

主题主要在 Windows 环境下使用。其他系统可能因字体名称和字体回退不同而出现显示差异。
