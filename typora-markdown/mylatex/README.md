# My LaTeX Typora 主题

`mylatex.css` 基于 [typora-latex-theme](https://github.com/Keldos-Li/typora-latex-theme) 修改，面向中文报告和打印排版。调整包括代码字体与代码块、正文中文字体回退、标题字体、字号、行距、页面边距和链接配色；自定义片段在 CSS 中以 `@nenhang` 标注。

## 安装与使用

将 `mylatex.css` 复制到 Typora 的主题目录，在 Typora 的主题菜单中启用。字体安装和来源说明见 [fonts/README.md](fonts/README.md)。主题和模板中还包含单独提供的字体文件；使用前请自行确认相应字体的授权。

## 报告封面模板

[`project-template/`](project-template/README.md) 提供两份可编辑的 Markdown 封面样例及资源说明：

- [实验报告封面](project-template/lab-report.md)
- [课程项目报告封面](project-template/project-report.md)

封面中的校徽、校名图像位于 [`project-template/images/`](project-template/images/)，封面预览位于 [`project-template/cover_examples/`](project-template/cover_examples/)。模板里的课程、姓名、学号等字段均为示例，使用前请替换。

## 兼容性说明

主题主要在 Windows 环境下使用。其他系统可能因字体名称、字体授权和 Typora 导出实现不同而需要调整。
