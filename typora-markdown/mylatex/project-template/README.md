# My LaTeX 项目报告封面模板

本目录提供两份配合 `mylatex.css` 使用的 Typora Markdown 封面样例：

- [`lab-report.md`](lab-report.md)：本科实验报告封面
- [`project-report.md`](project-report.md)：课程项目报告封面

## 模板资源

- [`images/`](images/)：浙大校徽和校名 SVG 图像
- [`cover_examples/`](cover_examples/)：封面 PNG 预览
- [`fonts/`](fonts/)：封面使用的中文字体文件

Markdown 文件中的课程名称、姓名、学院、专业、学号、教师和日期都是示例字段。请在 Typora 中打开后替换，并检查图片链接与字体是否可用，再导出 PDF。

字体文件的使用请遵守相应授权；字体名称或本机字体不可用时，需要同步修改 Markdown 中的 `font-family`。
