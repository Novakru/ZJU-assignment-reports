# ZJU Report Templates

本分支为 **工程技术前沿期中文献综述**，分支名
`assignment-engineering-frontiers-review`。当前工作与构建说明见
[frontiers-review/README.md](frontiers-review/README.md)。
当前已完成中文综述初稿，含3幅图、2张比较表与10篇参考文献；
另保留中文排版样稿与阅读材料。初稿使用AI辅助整理，作者信息与本人核阅仍待完成。
本分支从 `main` 建立，仅复用MP2的封面原则与官方ZJUI标识，不混入其代码和实验。

面向浙江大学学习与科研场景的 Typora 主题和 LaTeX 报告模板合集。包含本科课程/实验报告样例，以及独立的英文技术报告与论文模板。项目由个人维护，非浙江大学官方模板。
